# Changelog

## 1.0.0 — 2026-08-02

### Added

- Reusable responsive Studio workspace with accessible premium controls
- Excel-backed venue catalogue, safe dynamic sport enrichment, and offline support
- Typed poster model, style/concept directors, venue DNA, history, and personalisation
- Monaco benchmark illustration plus venue masters for four visual-QA landmarks
- Vector-first SVG/PDF and commercial raster/package export workflows
- Secure Electron desktop shell
- Core automated tests and repeatable 15-poster visual QA matrix

### Changed

- Root route now opens the Studio workspace
- Heavy preview and export features are loaded on demand
- Editorial contrast and recovery/error states are production-ready
- Production dependencies resolve to remediated PostCSS, Sharp, and official SheetJS releases

### Removed

- Legacy poster workflow, test-only API route, unsafe Excel writer, and unused rendering dependencies

### Known release constraints

- EPS requires an external trusted converter
- CMYK requires a licensed ICC transform
- Signed desktop installers require platform signing credentials
